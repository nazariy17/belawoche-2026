# Aircraft silhouettes

Original SVG artwork created for this project and distributed under the repository MIT license. Regenerate with `node scripts/create-aircraft-icons.mjs`.

Icons represent simplified visual groups, not certified wake-turbulence classes. Known ICAO aircraft types select a shape. ADS-B categories provide a fallback only; category A5 does not imply two or four engines. Unknown engine count gets a separate generic heavy icon. Unknown type/category uses a neutral directional outline. Type mapping is intentionally partial and can be extended in `src/app/aircraft-icons.ts`.
